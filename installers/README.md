# OfficeTab-rs — Instaladores Oficiais 📦✨

Esta pasta contém os instaladores pré-compilados do **OfficeTab-rs** prontos para uso no Windows 10 e 11 (64-bit), sem necessidade de instalar Rust ou compilar código fonte.

---

## 📥 Arquivos Disponíveis para Download

1. [**`OfficeTab-rs-Setup-v0.1.0.exe`**](./OfficeTab-rs-Setup-v0.1.0.exe) (**2.85 MB**)
   - **Instalador Oficial Gráfico (Inno Setup 6)**.
   - Assistente visual em Português e Inglês.
   - Instala e registra a DLL COM para **Word, Excel, PowerPoint, Access, Project, Visio e Publisher**.
   - Cria atalhos no Menu Iniciar e opção de desinstalação no Painel de Controle / Configurações do Windows.

2. [**`OfficeTab-rs-v0.1.0-Portable.zip`**](./OfficeTab-rs-v0.1.0-Portable.zip) (**1.66 MB**)
   - **Pacote Portátil Completo**.
   - Descompacte em qualquer pasta e use `Instalar.bat` para ativar ou `Desinstalar.bat` para remover.

---

## ⚡ Instalação Rápida em 1-Clique

- **Instalar:** Dê dois cliques em `Instalar.bat`.
- **Desinstalar:** Dê dois cliques em `Desinstalar.bat`.
- **Configurar:** Dê dois cliques em `Configurar.bat`.
- **Diagnóstico:** Dê dois cliques em `Testar.bat`.
